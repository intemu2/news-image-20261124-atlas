# The Tuesday Atlas — news-image-20261124

One image summing up Tuesday 24 November 2026 in world news.

- **42 stories, 6 continents**: 3 illustrated leads (Gaza, Zaporizhzhia,
  Nepal), 15 illustrated panels (numbered 4–18; Real Madrid 5–1 is panel 18),
  and a 24-item gazetteer (19–42) in 3 columns.
- **Light cream atlas style**: date masthead, specific scene illustrations
  per story, light world map with numbered region-coloured pins and labelled
  continents.
- Every story happened or was first reported on Tuesday 24 November 2026
  (UTC). Contested claims are marked as claims. See
  `../date-log-rebuild.md` for the per-story source log.
- Sources: Reuters, AP, AFP, UEFA, Xinhua, WHO, UN. Original drawings.

## Files

- `entry.png` — the entry image, 1024×1024, rendered with PIL
  (`../work/render_atlas.py`).
- `main.py` — stdlib-only entry point: copies `entry.png` to
  `$MAKEFUN_OUTPUT_DIR/entry.png`, failing hard on any size or hash
  mismatch.
